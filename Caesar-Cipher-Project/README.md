# Caesar Cipher Program

**Index Number:** 10373662

## Introduction

This project is a simple encryption and decryption program developed using Python. It runs in the command line and allows users to encrypt and decrypt text.

## Encryption Algorithm Used

The algorithm used in this project is the **Caesar Cipher**.

The Caesar Cipher is a basic encryption technique where each letter in a message is shifted forward or backward by a specific number of positions in the alphabet.

For example, using a key of 3:

- A becomes D
- B becomes E
- C becomes F

The same key is used to decrypt the message by shifting the letters backwards.

## Program Features

- Encrypts text entered by the user.
- Decrypts encrypted text.
- Allows the user to choose an encryption key between 0 and 25.
- Handles invalid key entries.
- Preserves spaces, numbers and special characters.
- Runs in the Python terminal.

## Programming Language

Python

## How to Run the Program

1. Make sure Python is installed on your computer.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Open the terminal.
5. Run the command below:

   `python caesar_cipher.py`

6. Follow the instructions displayed on the screen.
